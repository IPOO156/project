# 管理员 / 教师端重构原型

> 状态：**待评审**。本目录是纯静态 HTML 原型，不依赖构建、不请求后端。
> 尚未修改任何真实 Vue 代码；确认信息架构与视觉方向后再落实现有前端。

## 如何打开

- 直接双击 `index.html`。
- 或在项目根目录执行：

  ```bash
  python -m http.server 5500 --directory frontend/prototype/admin-console
  ```

  打开 `http://127.0.0.1:5500/`。

右下角「原型预览」可切换管理员 / 教师身份、明暗主题，并打开「查看改造说明」。
任意页面按 `Ctrl + K`（macOS 为 `⌘ + K`）可打开全局搜索。

## 设计方向

- 中性灰白 + 墨蓝 `#1d4ed8`，白底、1px 边框、4–6px 圆角，无渐变与装饰插画。
- 管理员 / 教师端恢复正常系统鼠标指针，不再启用书册光标。
- 13px 基准字号、44px 表格行高、数字等宽；筛选 → 指标 → 表格的固定阅读顺序。
- 动效只保留 120–160ms 的浮层与悬停反馈。
- 顶栏使用面包屑，不再使用多标签栏；消息入口移到铃铛 + 独立页面。
- 侧栏 5 组折叠：概览 / 档案业务 / 审核与评估 / 组织与人员 / 系统。

## 功能落点（不减少功能）

- **工作台**：待办、数据概览、快捷入口、系统公告、最近操作、角色与数据范围。
- **学生档案**：筛选、KPI、列表、组织汇总、统计分析、完整率分布；行点击打开档案抽屉。
- **档案导出**：导出任务、导出模板、表单字段模板；新建与下载保留。
- **材料审核**：待审核队列 + 详情、审核记录、审批委托；审核意见与通过 / 退回操作保留。
- **审批流程**：流程列表、节点预览、新建 / 编辑 / 停用。
- **指标体系**：14 项指标树、评分规则、重算批次；重算弹窗。
- **成果热力图**：学院 × 月份热力图、排行、明细与导出。
- **组织架构**：学校 / 学院 / 专业树、组织详情、下属专业、新增与编辑。
- **账号与角色**：账号、角色权限、数据范围、登录日志；新增账号与重置密码。
- **系统设置**：数据字典、学期设置、系统配置、定时任务、操作日志。
- **消息中心**：铃铛未读、消息列表 / 详情、筛选、全部已读、跳转关联业务。
- **全局**：个人信息、键盘快捷键、明暗主题、原型改造说明。

## 需要决定的问题

1. 教师端是否保留「学习建议」？原型按**移除**处理；如保留，建议放到用户菜单。
2. 教师端默认仅按权限展示 4 项（工作台、学生档案、档案导出、成果热力图）；原型额外放入「材料审核」模拟已授权。真实权限是否**维持严格过滤**？
3. 「审批委托」放在材料审核页签是否合适，还是应放到审批流程？
4. 「登录日志」目前在账号与角色，「操作日志」在系统设置。是否统一为一个「日志」页签？
5. 全局搜索首期只做页面 / 操作 / 消息跳转，**学生检索是否本期接入**？
6. 学生端本次不改动（书册视觉、多标签栏保留），请确认边界。

## 原型限制

- 全部为演示数据，不读写数据库、不请求接口。
- 表单提交、下载、分页、筛选等以 Toast 演示，不做真实持久化。
- 教师菜单按模拟权限过滤，未接入真实权限码。
- 仅覆盖管理员 / 教师端；学生端未改动。
