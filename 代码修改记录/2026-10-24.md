# 需求一：书册鼠标指针接入（book-cursor 项目化）

## 〇、背景

外部包 `book-cursor-v1.0.0` 为 UMD 自包含 JS，运行时用 data URI 生成 8 态书册光标。原包与本项目的差异点：

- 原包为无类型 UMD；本项目为 Vue 3 + TS 严格模式，禁止 `as any`；
- 原包配色为通用暖色；本项目有深海蓝 + 琥珀金设计 token；
- 原包带 `prefers-reduced-motion` 冻结分支；本项目策略为「动效始终启用」；
- 原包主题判定兼容 Bootstrap；本项目主题机制为 `html[data-theme='light'|'dark']` + `.dark`；
- 原包 disabled 态 CSS 用 `--bc-na`，但 JS 写入的是 `--bc-not-allowed`，导致禁用态光标从未生效。

## 一、删除范围

无。本轮为新增文件与在既有启动/请求链路中增加调用，未删除既有代码。

## 二、新增范围

| 文件                                     | 内容                                                                                                                                                                                                       |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/shared/utils/bookCursor.ts`（新增） | 原包 TS 重写：`BookCursorOptions` / `BookCursorApi` 类型、项目配色 token、移除 reduced-motion 分支、主题判定收敛到 `data-theme` / `.dark`、修正 disabled 变量映射、补充 `.el-button` / `.el-link` 命中规则 |
| `src/main.ts`（修改）                    | 启动时 `bookCursor.init({ theme: 'auto' })`；主题切换由 MutationObserver 跟随                                                                                                                              |
| `src/shared/api/request.ts`（修改）      | 增加全局请求计数（`pendingRequestCount`）与 180ms 延迟触发，驱动光标「加载中」态；并发请求归零才恢复                                                                                                       |

## 三、影响范围

- 全局鼠标指针替换为书册样式，日夜配色随主题切换；
- 请求层：短请求不闪烁，长请求/并发请求才进入翻页加载态；
- Safari 对 SVG 光标支持不稳定，会回退为系统箭头（原包已知限制）；
- 若后续配置 CSP，需允许 `img-src data:`。

# 需求二：加载页温馨提示（让既有 loading 组件真正生效）

## 〇、背景

`DefaultLayout.vue` 中已有完整页面级 loading（spinner + 「加载中…」+ 220ms 入场），但其数据源 `appStore.pageLoading` 在全仓**没有任何调用方**，该组件实际从未出现。

本轮补上触发链路，并在加载页加入学习/成长建议。

## 一、删除范围

无。

## 二、新增范围

| 文件                                          | 内容                                                                                                               |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `src/shared/constants/loadingTips.ts`（新增） | 10 个主题、60 条通用建议 + 8 条年级专属建议；路由/角色主题解析、年级解析、随机抽取（避免连续重复）、收藏与屏蔽 API |
| `src/app/router/loadingIndicator.ts`（新增）  | 慢导航触发：400ms 延迟显示；显示后至少停留 1.2s；首屏与 `noLayout` 路由跳过；重定向/取消不误收尾                   |
| `src/app/router/routes.ts`（修改）            | 在鉴权守卫之后注册 `setupNavigationLoading(router)`                                                                |
| `src/shared/ui/LoadingTipCard.vue`（新增）    | 加载页提示卡：分类标签、换一条、收藏、屏蔽此类；4.2s 自动轮播，悬停/聚焦暂停                                       |
| `src/shared/ui/StudyTipInline.vue`（新增）    | 空状态用内联建议（与加载页共用同一提示库）                                                                         |
| `src/app/layouts/DefaultLayout.vue`（修改）   | 加载遮罩内挂载提示卡；加载出现时按新路由重新抽取                                                                   |

## 三、影响范围

- 只有真正慢的导航才出现加载页，短导航不打扰；
- 提示按页面场景匹配：申报/奖项 → 论文/实习/成长；职业规划 → 考研/留学/求职/创业；教师端 → 教学审核；
- 页面内部数据加载仍由各页面 `v-loading` 表达，不复用全局遮罩。

# 需求三：学习建议延伸（空状态 / 年级 / 收藏与屏蔽）

## 〇、背景

在需求二基础上继续落地三项建议：

1. 空状态停留时间比加载页长，更适合展示一条建议；
2. 建议按年级收敛：大一适应、大二探索、大三聚焦、大四收口；
3. 允许收藏喜欢的建议、屏蔽不感兴趣的主题，并提供管理入口。

**排查发现**：`EmptyState.vue` 虽已存在并被 `shared/ui/index.ts` 导出，但全项目**无任何页面使用**；实际空状态均为各页面原生 `el-empty`。因此本轮采用「共享内联组件 + 插入真实 el-empty 插槽」的方式落地，避免改造成无人使用的死代码。

## 一、删除范围

无。

- 空状态：4 个学生端高频页面出现「小建议」，可换一条；

- 偏好属账号级数据，登出时随用户级存储一起清理；
- 未引入任何新依赖。
