## 一、删除范围（先于新增记录）

### 1.1 删除的装饰与无效样式

| 文件/范围                                                                                                     | 删除内容                                            | 原因                                                 |
| ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------- |
| `assets/styles/teacher-console.scss`                                                                          | 静态卡片 hover `translateY`、标题渐变、装饰眉标显示 | 减少页面晃动和展示型噪声                             |
| `features/messages/MessageCenter.vue`、`activities/ActivityList.vue`                                          | 列表逐行错峰动画、重复空态                          | 管理后台不需要逐行动画；空态统一由表格 `#empty` 承载 |
| `shared/ui/GreetingToast.vue`、`features/dashboard/composables/useGreeting.ts`                                | emoji、分时段渐变配色                               | 统一品牌色，避免花哨                                 |
| `features/teacher/heat-map/HeatMap.vue`                                                                       | 装饰光晕/强调色块                                   | 让视觉重心回到数据矩阵                               |
| 多个教师页                                                                                                    | 英文眉标、标题装饰图标、无功能按钮图标              | 降低视觉噪声，标题直接可读                           |
| `features/teacher/system-config/components/AnnouncementPanel.vue`、`form-customization/FormCustomization.vue` | 装饰性图标与冗余提示                                | 操作仍保留，仅去掉装饰                               |

| 文件                                                                    | 删除内容                                               | 原因                             |
| ----------------------------------------------------------------------- | ------------------------------------------------------ | -------------------------------- |
