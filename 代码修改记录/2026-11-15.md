## 四、前端无法独立完成、需后端支持的项

| 事项                            | 现状                                                                                     | 需要的后端能力                                                                              |
| ------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 规划正文保存为草稿              | 仅有 `PUT /activities/career_plan/{id}`，保存后强制置待审批并升版本                      | `PUT /profile/career-plans/{planId}` 或活动编辑接口支持 `isDraft=1`，草稿正文保存不触发审核 |
| 撤回后的规划再编辑              | 活动编辑 `checkEditable` 仅允许草稿(0)/已退回(3)                                         | 允许已撤销(4)进入编辑，否则撤回后只能删除                                                   |
| 行动成果文件删除/解绑           | 仅有新增接口，删除行动时才级联清理                                                       | `DELETE /profile/career-plans/{planId}/actions/{actionId}/files/{fileId}`                   |
| 规划附件（evidenceFileIds）删除 | 绑定后 `file_status=2`，`DELETE /common/files/{fileId}` 拒绝删除（提示「请先取消关联」） | 提供附件解绑接口，或允许草稿/已退回规划调用通用删除                                         |
| 新增里程碑直接带佐证            | `addMilestone` 不接收 `proofFileId`，前端需二次 PUT                                      | `CareerMilestoneAddRequest` 增加 `proofFileId`                                              |
| AI 建议采纳资格                 | `ai-add` 要求建议必须关联 `weaknessId` 且归属当前用户，否则 403                          | 建议列表返回 `canAdopt` 标记（或对教师建议放宽归属校验），前端据此控制按钮                  |
| 详情展示版本/提交次数           | 详情 DTO 无 `currentVersion/submitCount`（仅列表有）                                     | 详情响应补充两个字段（当前已在列表展示）                                                    |
| 导出文件名                      | 后端 302 到 OSS，文件名依赖 OSS 响应头                                                   | 302 目标或代理下载响应携带 `Content-Disposition: attachment; filename=...`                  |

## 五、说明

| 事项         | 说明                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------- |
| 草稿校验     | 后端 `semesterId/title` 为必填，保存草稿同样要求学期与标题；已填一半的目标/行动仍按提交规则校验，避免静默丢弃 |
| 正文编辑语义 | 因后端无独立更新接口，正文编辑实际是「修改后重新提交」；弹窗已明确提示「保存后会重新提交审核，版本号加一」    |
| 进度口径     | 列表「进度」与顶部「计划完成进度」均使用后端 `progressRate`；学期覆盖度仅作辅助展示，不再参与百分比计算       |
| 里程碑佐证   | 新增里程碑带佐证时会产生「新增 + 更新」两次请求；第二次失败时里程碑已创建但未绑定佐证，可再次编辑补绑         |
| 删除/撤回    | 前端按后端状态规则控制按钮：待审批只显示撤回，草稿/已退回/已撤销才显示删除；已通过只读                        |
