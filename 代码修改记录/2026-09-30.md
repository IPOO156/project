# 二、需求二：Element Plus 按需化与 Vite 构建优化（P0/P1）

## 2.1 删除范围

### `src/main.ts`

| 删除内容                                               | 说明                                                                                           |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `import ElementPlus from 'element-plus'`               | 全量组件注册，与 `unplugin-vue-components` 的 `ElementPlusResolver` 冲突，使 tree-shaking 失效 |
| `import zhCn from 'element-plus/es/locale/lang/zh-cn'` | 移至 App.vue 配合 ElConfigProvider 使用                                                        |
| `app.use(ElementPlus, { locale: zhCn })`               | 模板内 el-* 组件改由 unplugin 自动按需注册                                                     |

## 2.2 新增范围

### `src/main.ts`

| 新增/保留内容                                                             | 说明                                                                                                                                                                   |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 保留 `import { ElMessage } from 'element-plus'`                           | 代码中大量 JS 式显式调用，unplugin 不为显式 import 自动注入样式                                                                                                        |
| **保留** `import 'element-plus/dist/index.css'` 全量 CSS 与 dark css-vars | 经最小化构建实验验证：显式 import 的 ElMessage 等组件样式不会被 resolver 自动注入，全量 CSS 是保证样式不缺失的保守方案；CSS 单文件可被浏览器缓存，风险低于 JS 全量入包 |
| 其余初始化逻辑（initAuthState、pinia、router、全局错误处理）不变          | —                                                                                                                                                                      |

### `src/App.vue`

| 新增内容                                                                               | 说明                                                        |
| -------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 模板最外层包 `<el-config-provider :locale="zhCn"><router-view /></el-config-provider>` | 组件库中文文案由 ConfigProvider 承载，无需 app.use 全量注册 |
| `import zhCn from 'element-plus/es/locale/lang/zh-cn'`                                 | 从 main.ts 迁入                                             |

### `vite.config.js`（注意生效配置文件为 .js）

| 新增内容                                                                                                                                                              | 说明                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `build.target: 'es2015'`                                                                                                                                              | 明确构建目标                                                                                                     |
| `chunkSizeWarningLimit: 1000`                                                                                                                                         | 适配分包后的大 chunk 告警阈值                                                                                    |
| `manualChunks(id)` 函数式分包：element-plus/@element-plus → `element-plus`；echarts/zrender/vue-echarts → `echarts`；vue/@vue/vue-router/pinia/axios/dayjs → `vendor` | **必须用函数形式**：对象语法会把 element-plus 根入口及其全部依赖打入分包导致 tree-shaking 失效（已在注释中说明） |

### 自动生成文件（非手工编辑）

- `auto-imports.d.ts`、`components.d.ts`：unplugin 按按需注册结果重新生成。
- `package-lock.json`：执行 npm 命令时被 npm 重新解析收敛（lodash-es/lodash-unified 等条目元数据变化，净减约 84 行）；`package.json` **未改动**，无新增/删除依赖。
