# 首页多维度画像雷达图按维度自适应刻度

- **日期**：2026-11-19
- **修改人**：ry
- **本次需求**：雷达图此前五个轴统一按 `max: 100` 绘制，而各维度满分/目标口径不同（如学业 40 分、社会实践 20 分），导致当前得分多边形被压在圆心附近、图形拥挤。改为每条轴按该维度自身峰值自适应刻度。
- **涉及范围**：`src/features/dashboard/ProfileRadarCard.vue`。

## 一、删除范围

| 文件 / 位置                                                    | 删除内容        |
| -------------------------------------------------------------- | --------------- |
| `src/features/dashboard/ProfileRadarCard.vue` 雷达 `indicator` | 统一 `max: 100` |

## 二、新增范围

| 文件 / 位置                                   | 新增内容                                                                                            |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `src/features/dashboard/ProfileRadarCard.vue` | `axisMax(item)`：取当前/目标/上阶段峰值的 1.1 倍作为该轴上限；`indicator` 改为 `max: axisMax(item)` |

## 三、说明

- 每条轴的比例由「得分 / 100」改为「得分 / 该维度峰值 × 1.1」，峰值含当前值、目标值与有基线时的上阶段值，避免任一序列超出轴范围。
