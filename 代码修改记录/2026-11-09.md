# 修复动态记录中职业规划「查看」跳转到个人档案申报

- **日期**：2026-11-09
- **修改人**：ry
- **本次需求**：动态中心「报名记录」里职业规划记录的「查看」跳转到了个人档案申报（竞赛填报页），应进入成长发展页并直接打开该规划详情。
- **原因**：`GET /activities` 聚合 archives / award_applications / career_plans 三张表。职业规划列表项没有 `archive_type`，前端按空串推导类型，`sourcePath` 拼成 `/applications?tab=`，ApplicationHub 无 tab 时回落竞赛申报页；`activityCategoryOf('')` 也把职业规划当作 `archive`，删除/撤回归类同样错误。
- **改动范围**：仅前端提交记录映射、路由工具、职业规划记录卡片与类型/字典；后端与接口未改动。

## 一、删除范围

| 文件 / 位置                                                 | 删除内容                                                                                 |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `src/shared/api/submission/record-query.ts`                 | 删除仅凭 `archive_type` 推导记录类型与来源页的写法（职业规划该字段为空，导致类型为空串） |
| `src/shared/api/submission/record-utils.ts`                 | 删除 `activityCategoryOf` 只按「之星 / 其他」二分、其余一律归 `archive` 的逻辑           |
| `src/features/profile/components/CareerPlanRecordsCard.vue` | 删除模板中内联关闭详情的 `@close="detailVisible = false"`，改由统一关闭方法清理地址参数  |

## 二、新增范围

| 文件 / 位置                                                 | 新增内容                                                                                                                   |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `src/shared/types/types.ts`                                 | 新增 `SubmissionRecordType = ApplicationType \| 'career_plan'`，`SubmissionRecord.type` 改用该类型                         |
| `src/shared/api/submission/record-query.ts`                 | 依据列表项顶级 `type === 'career_plan'` 识别职业规划；类型标签取 `APPLICATION_TYPE_MAP.career_plan`，来源页携带记录 id     |
| `src/shared/api/submission/record-utils.ts`                 | `sourcePathOf` 增加 `career_plan → /profile/career-plan[?planId=<id>]`；`activityCategoryOf` 对 `career_plan` 返回同名分类 |
| `src/shared/constants/dict.ts`                              | `APPLICATION_TYPE_MAP` 增加 `career_plan: '职业规划'`，供列表类型回显与类型筛选使用                                        |
| `src/features/profile/components/CareerPlanRecordsCard.vue` | 监听 `route.query.planId` 自动打开对应规划详情；关闭详情时用 `router.replace` 清掉 `planId`，保证再次点击可重新打开        |
| `tests/unit/submissionRecordUtils.spec.ts`                  | 新增单测锁定职业规划路由/分类映射及既有申报类型路由不被破坏                                                                |
