## 一、删除记录

### 1.1 表单自定义静态占位页面整体替换

**涉及文件**：`src/features/teacher/form-customization/FormCustomization.vue`

**删除内容**：原静态/mock 占位实现（无真实接口对接），整体重写为对接 `/admin/form-templates` 全量 CRUD 的动态字段编辑器页面。

**删除原因**：后端存在完整表单模板接口但前端仅有占位页，属于「后端有接口、前端无页面」的补齐场景。

### 1.2 API 模块移除无效导入

**涉及文件**：`src/shared/api/teacher.ts`

**删除内容**：未使用的 `FormTemplateFieldItem`、`TeacherExportJob` 类型导入。

### 1.3 移除后端不支持的 no-op 关键词搜索框

**涉及文件**：

- `src/features/teacher/system-config/SystemConfig.vue`
- `src/features/teacher/delegation/DelegationManage.vue`

**删除内容**：`/admin/announcements` 与 `/teacher/delegations` 列表接口均**无 keyword 参数**，删除两页此前无实际作用的「关键词」搜索输入框及对应过滤逻辑。

**删除原因**：CLAUDE.md 3.5 要求搜索字段必须可用；无对应后端参数时不得保留无效搜索框。

### 1.4 清理无效/冗余代码

**涉及文件**：

- `src/features/teacher/delegation/DelegationManage.vue`：移除未使用的 `Handshake` 图标导入
- `src/features/teacher/student-detail/StudentDetail.vue`：移除未使用的 `eventTypeLabel` 函数

## 二、新增/修改记录

### 2.1 API 模块：迁移 `/admin/**` → `/teacher/**`（`src/shared/api/teacher.ts`，修改）

| 函数                      | 迁移后接口                                         |
| ------------------------- | -------------------------------------------------- |
| `submitArchiveExport`     | `POST /teacher/exports`                            |
| `triggerScoreRecalculate` | `POST /teacher/scores/recalculate`                 |
| `getRecalculationTask`    | `GET /teacher/scores/recalculation-tasks/{taskId}` |
| `getStatisticsHeatmap`    | `GET /teacher/statistics/heatmap`                  |

### 2.2 API 模块：新增教师端接口函数（`src/shared/api/teacher.ts`，修改）

- **学生成长档案**：`getTeacherStudentProfile` / `getTeacherStudentTimeline` / `getTeacherStudentWeaknesses` / `getTeacherStudentCareerPlans` / `submitTeacherCareerFeedback` / `addTeacherImprovementSuggestion`（对应 `/teacher/students/*`、`/teacher/career-plans/*/feedbacks`、`/teacher/improvement-suggestions`）
- **审批委托**：`listTeacherDelegations` / `createTeacherDelegation` / `cancelTeacherDelegation`（`/teacher/delegations`）
- **系统配置与公告**：`listSystemSettings` / `updateSystemSetting` / `listAnnouncements` / `createAnnouncement` / `updateAnnouncement` / `deleteAnnouncement`（`/admin/settings`、`/admin/announcements`）
- **定时任务**：`listScheduledTasks` / `updateScheduledTaskStatus`（`/admin/scheduled-tasks`）
- **表单模板**：`listFormTemplates` / `getFormTemplateDetail` / `createFormTemplate` / `updateFormTemplate` / `deleteFormTemplate` / `setDefaultFormTemplate`（`/admin/form-templates`）
- **导出扩展**：`getExportTemplates` / `listTeacherExportJobs` / `deleteTeacherExportJob`（`/teacher/exports/templates`、`/teacher/exports`）

### 2.3 API 模块：契约修正（`src/shared/api/teacher.ts`，修改）

- `getTeacherStudentProfile`：展开后端嵌套结构 `{isInScope, profile:{...}}`，返回拍平后的 `TeacherStudentProfile`（含 `isInScope`）。
- `refreshTeacherStatistics`：`semesterId` 由 body 改为 **query 参数**（后端 `@RequestParam`）。
- `listSystemSettings`：返回类型由 `SettingItem[]` 修正为 `Promise<PageResult<SettingItem>>`，调用方取 `res.list`。
- `listAnnouncements`：`targetType` 由数字改为**字符串枚举** `all/college/major/class`；移除 keyword 参数。

### 2.4 类型新增/修改

**`src/shared/types/teacher.ts`**（修改）：

- 新增 `TeacherStudentProfile`、`GrowthTimelineResponse`、`WeaknessItem`、`CareerPlanDetailResponse`、`CareerFeedbackItem`、`TeacherDelegationItem`、`DelegationCreatePayload`、`SettingItem`、`AnnouncementItem`、`AnnouncementPayload`、`ScheduledTaskItem`、`TeacherExportTemplate`、`TeacherExportJobItem` 等约 25 个接口。
- 新增 `FormTemplateOption {value,label}`；`FormTemplateFieldItem.options` 类型为 `FormTemplateOption[] | null`。
- `AnnouncementItem.targetType` 改为 `string | null`，移除不存在的 `targetTypeLabel`。

**`src/shared/types/types.ts`**（修改）：

- `ROLE_PERMISSIONS` 中 `super_admin` 与 `admin` 角色新增 `delegation`、`system-config`、`scheduled-task` 三个权限点。

### 2.5 路由登记（`src/app/router/teacher-routes.ts`，修改）

新增 4 条路由：

- `/teacher/student-detail/:userId`（权限 `archive-view`，meta 备注 `isInScope` 提示）

对接 `/admin/form-templates` 全量 CRUD：列表 + 新建/编辑弹窗 + 动态字段编辑器（9 种字段类型，select/radio/checkbox 支持选项），`options` 在 UI 层用字符串数组、提交时转为后端 `{value,label}` 结构；编辑态禁用 code/category 输入（后端更新接口不支持）；支持「设为默认」。
