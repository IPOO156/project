- **改动范围**：仅前端头像裁剪组件；上传接口、文件名与后端均未改动。

无删除代码。仅改变透明画布直接编码为 JPEG 的输出流程。

| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/features/profile/components/AvatarUploader.vue` | `generateCroppedAvatar` 在输出画布绘制前先铺白色不透明底（`fillRect` 256×256），再绘制圆形裁剪结果；附注释说明 JPEG 透明像素陷阱及白色四角不可见的原因 |

# 修复头像上传后破图（OSS 预签名 URL 过期）

- **日期**：2026-11-10
- **修改人**：ry
- **本次需求**：档案概览上传头像后，头像位置显示为破图（alt「用户头像」）；后端重新部署头像修复后，前端补上签名地址刷新与加载失败兜底。
- **根因**：
  1. 后端头像曾把 30 天有效期的 OSS V4 预签名 URL 直接存库，而 V4 签名 URL 最长只有 7 天（604800 秒），过期后 OSS 拒绝访问，`<img>` 变成破图。后端已改为只存 `objectKey`、读取时现签 7 天 URL（`OssFileService.resolveAvatarUrl`）。

  3. `AvatarUploader` 的 `<img>` 没有加载失败处理，地址失效时直接渲染浏览器破图图标。
- **改动范围**：仅前端用户 Store、根组件、头像上传组件与对应单测；后端、接口与代理地址均未改动。

# 修复学科申报保存草稿后前端显示两条草稿（本地草稿与后端草稿重复）

- **日期**：2026-11-10
- **修改人**：ry
- **本次需求**：学科申报点击「保存草稿」后，后端数据库只有一条草稿，但前端记录列表同时显示本地草稿与后端草稿两行（第二行带「版本」操作）。
- **根因**：
  1. 保存草稿是双写：`saveLocal()` 写 localStorage，`saveToBackend()` 以 `isDraft=1` 建后端草稿；但后端保存成功后从未删除本地副本，`useFormRecords.loadRecords()` 又无条件把本地草稿拼在真实记录之前，于是同一份草稿显示两行。
  2. `handleSaveDraft()` 未等待后端保存完成就刷新列表，刷新时后端草稿可能已建出、本地草稿又还在，进一步放大重复。
  3. 本地草稿没有记录自己对应的后端 id，编辑/删除本地草稿时无法定位同一条后端记录：再次保存会又 POST 一条新草稿，删除也只清本地副本。
- **改动范围**：`useFormDraft` / `useFormRecords` / `useApplicationPage` 三个公共 composable 及单测；接口字段、后端、页面模板均未改动。

| `src/shared/composables/useFormDraft.ts`       | 删除 `saveToBackend()` 建草稿/autosave 成功后不处理本地草稿副本的写法                              |

## 四、说明

| 事项      | 说明                                                                                                                                         |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 展示结果  | 保存草稿后列表只保留一条草稿；后端保存成功时展示后端记录（含「版本」），后端不可用时展示本地草稿并提示「草稿已保存到本地」                   |
| 旧数据    | 已存在、没有 `__backendId` 的本地草稿会按「草稿状态 + 同标题」自动关联一次，无需手动清缓存；若同一标题存在多条后端草稿，只隐藏匹配到的第一条 |
| 编辑/删除 | 本地草稿编辑时自动定位其关联的后端草稿，不会再重复建记录；删除时会连同后端草稿一起删除，避免刷新后「复活」                                   |
| 自动保存  | 800ms 防抖 autosave 成功后同样会清掉本地副本（后端已是最新内容）；失败则保留本地兜底                                                         |
