# 首页多维度画像「距目标」分数出现浮点长尾

- **日期**：2026-11-17
- **修改人**：ry
- **本次需求**：首页「多维度画像评估」卡片中「距目标」显示为 `3.3999999999999986分` 等长尾值，要求只保留两位小数；同类问题（AI 职业规划短板分析的「差 X 分」文案）一并修正。
- **对接依据**：`/home/dashboard` 返回 `indicators[].gap`（后端已按 `DECIMAL(5,2)` 取整，如 3.40）；`poster_evaluation_scores.gap` 同理。
- **涉及范围**：首页画像卡片及其维度映射、AI 职业规划短板分析。

## 一、删除范围

| 文件 / 位置                                             | 删除内容                                                             | 原因                                                                           |
| ------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `src/features/dashboard/ProfileRadarCard.vue`           | `gapToTarget: item.target - item.current` 的前端浮点相减             | 后端已返回干净的 `gap`，前端重算会带出 `3.3999999999999986` 这类二进制浮点误差 |
| `src/features/ai-chat/composables/useCareerAnalysis.ts` | `analyzeCareer` 中 `.map((d) => ({ d, gap: d.target - d.current }))` | 同样的前端浮点相减，会让短板文案出现「差 3.3999999999999986 分」               |
| `src/shared/types/types.ts`                             | `WeaknessItem.gap` 旧注释「差距 = target - current」                 | 口径已改为优先后端 gap，注释同步更正                                           |

## 二、新增范围

| 文件                                                    | 新增内容                                                                                                                                                         |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/shared/types/types.ts`                             | `ProfileDimension` 增加可选 `gap` 字段（后端 `indicators[].gap`），注明禁止用 target-current 重算                                                                |
| `src/features/dashboard/Dashboard.vue`                  | `profileDimensions` 按 `dimensionCode`/`dimensionName` 关联 `home.indicators`，把后端 `gap`、`targetScore` 带入维度对象（`HomeDashboard` 类型注解替代 any 推断） |
| `src/features/dashboard/ProfileRadarCard.vue`           | `resolveGap()`：优先用后端 `gap`，缺失时用差值兜底并 `Math.round(x*100)/100` 收敛两位；兼容后端 BigDecimal 序列化为字符串的情况                                  |
| `src/features/ai-chat/composables/useCareerAnalysis.ts` | 新增 `resolveGap()`：优先后端 `gap`，缺失时用差值兜底并收敛两位小数；`analyzeCareer` 改用该函数，短板描述与「差 X 分」文案同步收敛                               |
