# 成长总结统计区拆分为四张独立卡片

- **日期**：2026-11-17
- **修改人**：ry
- **本次需求**：成长时间轴「成长总结」模块的 4 项统计（经历 / 技能 / 平均成长 / 潜力）由一整块带分隔线的统计面板，改为四张各自独立的卡片。
- **涉及范围**：仅 `src/features/growth-timeline/components/SummarySection.vue` 的样式部分，脚本与模板未改动。

## 一、删除范围

| 文件 / 位置                                      | 删除内容                                                                                    | 原因                                                 |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `SummarySection.vue` `.summary-grid`             | `border`、`border-radius`、`background`、`box-shadow`、`overflow: hidden`                   | 外层面板不再承担卡片外观，改由单张卡片各自承载       |
| `SummarySection.vue` `.summary-card`             | `border-left` 分隔线、`background: transparent`                                             | 卡片之间改为留白间距，不再用分隔线切分同一块面板     |
| `SummarySection.vue` `.summary-card:first-child` | 首项 `border-left: none` 规则                                                               | 分隔线已移除，规则失效                               |
| `SummarySection.vue` 移动端 2×2 适配             | 第 3/4 项的 `border-top` 补线及暗色补线规则                                                 | 由 grid `gap` 留白替代，无需再补横向分隔线           |
| `SummarySection.vue` 暗色适配                    | `.summary-grid` 的 `border-color`/`box-shadow`、`.summary-card` 的 `border-left-color` 规则 | 边框与阴影已下沉到 `.summary-card`，对应规则同步迁移 |

## 二、新增范围

| 文件                 | 新增内容                                                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `SummarySection.vue` | `.summary-grid` 改为 `gap: 1.25rem` 的四列 grid，仅保留整体入场动画                                                                |
| `SummarySection.vue` | `.summary-card` 新增独立 `border`、`border-radius: $radius-2xl`、`background: var(--gt-card)`、双层阴影，过渡属性补充 `box-shadow` |
| `SummarySection.vue` | `.summary-card.is-revealed:hover`：悬停上浮 4px + 加深阴影 + `transition-delay: 0s`（避免继承入场错峰延迟导致悬停卡顿）            |
| `SummarySection.vue` | 移动端（≤768px）：`gap: 1rem`，2×2 排列；卡片内边距与数值字号沿用原移动端设置                                                      |
| `SummarySection.vue` | 暗色模式：`.summary-card` 边框与阴影、`.summary-card.is-revealed:hover` 悬停态按蓝灰卡面重写                                       |
