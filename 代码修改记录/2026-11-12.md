# 输入框选中（焦点）动画改为平滑扩散

- **日期**：2026-11-12
- **修改人**：ry
- **本次需求**：输入框获得焦点时，外圈描边是瞬间跳出的，与边框颜色渐变不同步，观感生硬；改为平滑扩散的焦点动画。

- **改动范围**：仅 `controls.scss` 中控制层焦点样式（输入框 / 文本域 / 下拉选择器）；学生端样式、业务组件与后端均未改动。

## 二、新增范围

| 文件 / 位置                       | 新增内容                                                                                                                                           |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/assets/styles/controls.scss` | 输入框 / 选择器用 `::after` 伪元素画 2px 外环（`inset: -4px`，保留旧 `outline-offset: 2px` 的留白），焦点时 `opacity 0→1 + scale(0.97→1)` 平滑扩散 |
| `src/assets/styles/controls.scss` | 文本域因 `textarea` 不渲染伪元素，改用双层 `box-shadow`（0 扩散 → 2px）实现同款动画，并补回 `is-error` 红边状态                                    |

# 奖项报名页切换后整页空白修复

- **日期**：2026-11-12
- **修改人**：ry
- **本次需求**：竞赛之星/双创之星首次点击正常，切到其他页面后再点这两个（以及科研之星）整页空白，必须刷新浏览器才有内容。
- **根因**：
  - `DefaultLayout` 的路由出口是 `<Transition name="layout-route" mode="out-in">`，要求路由组件只有一个可动画根节点；
  - 竞赛之星/双创之星模板为「表单 + 3 个弹窗」的并列多根结构，被编译成 Fragment。out-in 模式下，Fragment 的离开走 `unmount` 的 Fragment 分支，不会调用 `transition.afterLeave`，BaseTransition 的 `isLeaving` 永远保持 true，此后整个路由出口只渲染占位注释；
  - 该状态是全局的：从多根页离开后，再点任何页面（含本身单根的科研之星）都是空白，直到整页刷新；
