# 需求 2：成长时间轴新增/删除接线真实后端（4.2.1 POST + 4.2.4 DELETE 落库）

- **日期**：2026-09-01
- **修改人**：ry
- **需求来源**：后端已新增 `ProfileGrowthTimelineController` 实现成长时间轴写接口；用户提供「4.2.4 删除成长时间轴事件」契约并询问「没有实现删除功能吗」——此前 `archive.ts` 的 `addTimelineEvent`/`deleteTimelineEvent` 是 Mock（`setTimeout` resolve、不落库），删除不持久、新增刷新即消失。本次将 4.2.x 四个写接口全部接线，并修正删除流程防止伪删除。

---

## 一、删除记录

### 1.1 移除 Mock 占位实现

**涉及文件**：`src/shared/api/archive.ts`、`src/features/growth-timeline/composables/useGrowthTimeline.ts`

**删除内容**：

1. `addTimelineEvent` 的 `setTimeout` 伪实现（不落库，返回 `{ id: String(Date.now()), ...data }`）。
2. `deleteTimelineEvent` 的 `setTimeout` 伪实现（忽略形参直接 resolve）。
3. `useGrowthTimeline.addExperience` 旧版向后端传前端字段名（`semester/type/title/description/date`）的假调用，以及 `deleteExperience` 直接把前端前缀 id（`backend-*`/`local-*`）当真实 id 传给删除接口的错误调用。

**删除原因**：后端 4.2.x 写接口已实现（`ProfileGrowthTimelineController`），Mock 导致「新增刷新消失」「删除刷新后恢复」。

---

## 二、新增/修改记录

### 2.1 契约层新增 4.2.x 类型与四个真实接口

**涉及文件**：`src/shared/api/archive.ts`（**修改**）

**新增内容**：

1. 类型 `TimelineAbility` / `TimelineEventPayload` / `TimelineEventDetail`（字段对齐后端 `GrowthTimelineCreateRequest` 与接口文档 4.2.x）。
2. `addTimelineEvent(data)` → `POST /profile/growth-timeline`（4.2.1）
3. `getTimelineEventDetail(id)` → `GET /profile/growth-timeline/{id}`（4.2.2）
4. `updateTimelineEvent(id, data)` → `PUT /profile/growth-timeline/{id}`（4.2.3）
5. `deleteTimelineEvent(id)` → `DELETE /profile/growth-timeline/{id}`（4.2.4，后端软删除主记录 + abilities/tags 子记录）

### 2.2 新增经历同步落库 + 真实 id 回填

**涉及文件**：`src/features/growth-timeline/composables/useGrowthTimeline.ts`（**修改**）

**修改内容**：`addExperience` 由「仅本地」改为「本地立即展示 + 后端落库 + 真实 id 回填」：

- 字段映射：`title→eventName`、`description→content`、`date→eventAt`、`tags→tags`；奖项报名来源（`sourceType === 'award_applications'`）归类 `eventType=1`（奖项），其余默认 `eventType=6`（能力提升）。
- `sourceId + sourceType` 配对携带（后端 `uk_gt_source` 唯一校验）；未选来源时后端正常落库（status 默认 0=草稿，列表接口不按状态过滤，刷新仍可见）——已按后端源码核对并修正原注释中「未选择时后端返回 10001」的错误描述。
- 落库成功后把本地 id（`local-*`）回填为 `backend-{created.id}`；失败（网络/参数校验）保留本地经历。

### 2.3 删除流程接线 + 防止伪删除

**涉及文件**：`src/features/growth-timeline/composables/useGrowthTimeline.ts`（**修改**）

**修改内容**：`deleteExperience`：

- 用 `/^backend-(\d+)$/` 从前端 id 提取后端真实 id；仅对已持久化事件（`backend-{id}`）调 `DELETE /profile/growth-timeline/{id}`；本地未同步事件（`local-*`）不请求后端。
- **删除成功后才移除本地展示**：失败（网络 / 20005 无权限 / 30001 不存在）时保留记录，错误提示由 request 拦截器弹出——避免「本地先删、接口失败、刷新后记录复活」的伪删除。
