# 学生申报业务下拉接入后端真实字典（后端优先 + 常量兜底）

- **日期**：2026-11-08
- **修改人**：ry
- **本次需求**：学生端「竞赛级别 / 竞赛类型 / 获奖等级 / 项目级别 / 研究类型 / 组织级别 / 行业类型 / 企业类型 / 奖学金等级」等下拉此前全部使用前端写死常量，管理员在「字典管理」中维护的字典不会生效。本次将学生申报页的业务下拉统一改为读取后端 `GET /common/dict?dictType=xxx`，接口失败或返回空数组时回退前端常量，保证表单始终可填写；同时按后端 `dictionaries` 表校准常量取值，并为旧数据保留只读展示映射。
- **改动范围**：前端业务字典常量、`useRemoteDict` 组合式函数、8 个学生申报/之星页面、基本资料编辑、审批与教师详情展示、字典管理提示及对应单测。后端接口、字段、数据库均未改动；未新增 npm 依赖。

## 四、说明与遗留

| 事项                  | 说明                                                                                                                                                                                                                                                                                               |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 后端取值来源          | canonical 取值以 `D:\StudentArchives\sql\seed_dictionaries.sql` 为准；旧前端常量与之不符的已纠正：竞赛类型原误用级别码、研究类型 `development`→`experimental`、组织级别 `club/class`→`department/other`、行业类型/企业类型全部改为后端英文码、奖学金级别去掉 `college`、奖学金获奖等级补 `special` |
| 旧数据兼容            | 旧记录中的 `national/development/club/it/中文企业类型` 等码不进入可选下拉；审批/教师查看态通过 `displayOptions` 显示中文，学生重新编辑时需按新字典重新选择                                                                                                                                         |
| 生效时延              | 后端 `/common/dict` 为 5 分钟 Caffeine 缓存，前端同 TTL；字典管理修改最坏约 5–10 分钟生效，提示文案未承诺即时                                                                                                                                                                                      |
| 仍为前端常量/自由文本 | 学生状态（后端无 `/common/dict` 支持）仍用常量；证书类型、奖学金级别等按既定方案保持自由文本；`participant_role` 后端 seed 未提供，接口为空时回退 `ROLE_OPTIONS`                                                                                                                                   |
| 未做                  | 未使用批量接口 `/common/dict/batch`（单页最多 2 个字典类型，缓存与去重后请求量可控）；未做旧数据自动迁移                                                                                                                                                                                           |
