## 一、需后端处理（仅 3 项）

### 1.1 🔴 P0：V35 迁移 staging 验证（上线阻断）

| 项 | 内容 |
|----|------|
| 文件 | `src/main/resources/db/migration/V35__ensure_role_permissions_and_scopes.sql` |
| 改动 | permissions / role_permissions / role_scopes / user_roles 四张表幂等重建 |
| 风险 | INSERT IGNORE 依赖唯一键约束存在；如果老库唯一键有差异，可能导致授权重复或缺失 |
| **上线前必跑** | 在 staging 库执行 V35，验证下表： |

**验证 checklist：**
- [ ] `SELECT COUNT(*) FROM permissions` ≥ 130
- [ ] `SELECT COUNT(*) FROM role_permissions WHERE role_id = (SELECT id FROM roles WHERE code = 'admin')` ≥ 120
- [ ] `SELECT COUNT(*) FROM role_permissions WHERE role_id = (SELECT id FROM roles WHERE code = 'teacher')` ≥ 30（含 `delegate:manage`、`log:view`）
- [ ] `SELECT * FROM role_scopes WHERE user_id = (SELECT id FROM users WHERE user_no = 'A00002')` 有校级记录（scope_type=1）
- [ ] `SELECT * FROM role_scopes WHERE user_id = (SELECT id FROM users WHERE user_no = 'T00003')` 有学院级记录（scope_type=2）
- [ ] `SELECT role_id FROM user_roles WHERE user_id = (SELECT id FROM users WHERE user_no = 'A00002')` 返回 admin role id

### 1.2 🟡 P2：验证码自动获取 API

| 项 | 内容 |
|----|------|
| 现状 | AuthController 只有 `/auth/captcha` 公开端点，返回图片 + key，无测试绕过 |
| 影响 | 每次端到端测试登录浪费 30 秒+（必须手动输入 4 位验证码） |

### 1.3 🟡 P2：MessageService / MessageUnifiedService 两套并存

| 项 | 内容 |
