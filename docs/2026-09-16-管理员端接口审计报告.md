## 五、管理员端前端调用审批委托的问题

### 5.1 现状

- 管理员 A00002 登录 → 侧边栏"审批委托"菜单 → 点击
- 前端调 `GET /teacher/delegations`
- 后端 TeacherDelegationService：`adminAuthService.requireAdminOrPermission(teacherId, "delegate:manage")`
- V35 没给 admin 授 `delegate:manage`（注释说"审批委托为教师专属，不授予 admin"）
- **结果：20005 无权限**

### 5.2 根因

前端菜单注册里 `delegation` 模块的 `permissions` 只有 `[ADMIN_MENU_CODE]`（`system:manage`），这是个**过渡码**——admin 持 admin 角色直通 `requireAdminOrPermission` 的 admin 分支，但 Service 层查权限码时又找不到 `delegate:manage`。

### 5.3 建议

**产品决策项**：审批委托到底是"管理员委托教师审批"还是"教师之间互相委托"？

- 如果是**管理员发起委托给教师**：Service 层不该查 `delegate:manage`，应该查 admin 角色或其他管理员码
- 如果是**教师之间委托**：admin 不应该有这个菜单入口，前端菜单注册应该只给 teacher/counselor 角色可见

当前后端 V35 注释说"审批委托为教师专属"——那前端管理员端就不该有这个菜单入口。**需要在前端菜单注册里排除 admin 角色**。
