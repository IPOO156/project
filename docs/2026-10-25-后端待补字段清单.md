## 二、逐项说明

### 1. 职业规划记录契约（`GET /profile/career-plans`）

- **现状**：`CareerPlanRecord` 只有 `id / semester / title / submitDate / status / progressRate` 等字段。
- **需要新增**：
  - `teacherFeedback: string`：教师反馈正文
  - `reflection: string`：学生反思正文
  - 进度：`targetCount`（目标数）与 `actionDoneCount`（已完成行动数），或直接给出 `progressRate`（0-100）并保证列表与详情一致
- **影响页面**：个人中心 - 职业规划（详情抽屉、记录表格两列）
- **验收**：接口返回上述字段后，详情抽屉出现「教师反馈」「学生反思」，进度条不再依赖本地学期数估算。
- **前端位置**：`src/features/profile/CareerPlan.vue`、`src/features/profile/components/CareerPlanRecordsCard.vue`

### 2. AI 职业规划分析返回 `aiSuggestionId`

- **现状**：AI 分析由前端本地生成，未携带可回传的 `aiSuggestionId`，`/profile/career-plans/ai-add` 无法被安全调用。
- **需要**：分析结果每条建议带 `aiSuggestionId`（后端可识别的唯一标识），并确认 `ai-add` 接受该 id 入库。
- **验收**：前端点「采纳为计划」→ 携带 id 调 `ai-add` → 计划列表出现该条记录，重复采纳有幂等或明确报错。
- **前端位置**：`src/features/profile/components/CareerPlanAICard.vue`

### 3. 成长时间轴事件增加审核状态

- **现状**：时间轴事件无 `status`，前端只能展示类型/学期/日期/标题。
- **需要**：每条事件返回 `status`（或 `statusLabel`），取值与申报状态字典一致（草稿/待审批/通过/已退回）。
- **验收**：事件卡片出现状态标签，与申报记录状态一致。
- **前端位置**：`src/features/profile/components/GrowthRecords.vue`

### 4. 教师端档案导出支持字段级选择

- **现状**：前端按 `dataTypes: ['archives','scores']` 提交，导出接口未消费该参数，选择不起作用。
- **需要**：导出接口接收 `dataTypes`，并按所选类型裁剪导出列与数据；如需支持更多类型，请给出枚举清单。
- **验收**：只勾「成绩」导出时，文件内不含档案列。
- **前端位置**：`src/features/teacher/archive/ResearchExportDialog.vue`

### 5. 验证码有效期 `expiresIn`

- **现状**：`GET /auth/captcha` 只返回 `key` / `image`，倒计时按前端默认值。
- **需要**：返回 `expiresIn`（秒）。
- **验收**：后端把有效期调整为 60s 或 180s，前端倒计时自动跟随，无需改代码。
- **前端位置**：`src/shared/types/teacher/auth-types.ts`、`src/features/auth/composables/useLoginFlow.ts`

### 6. 教师端组织管理：真实学生人数

- **现状**：学院/专业/班级列表的人数为占位口径，未按学生档案的班级归属统计。
- **需要**：提供一个按组织节点统计的学生人数（或在使用现有接口时补 `studentCount` 字段）。
- **验收**：某班级显示的人数与档案中该班学生数一致。
- **前端位置**：`src/features/teacher/org/OrganizationManagement.vue`
