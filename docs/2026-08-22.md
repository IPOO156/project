# 2026-08-22 修改记录

> 需求：**保存草稿 / 提交记录列表**问题——保存草稿后刷新，申报内容会回填但下方记录不显示；保存多个草稿后刷新下方记录消失；提交成功后下方也不显示记录；要求草稿与已提交记录**同时展示**且刷新后草稿仍可见。
>
> 诊断过程中另发现 **7/10 申报类型提交返回 10003 请求数据格式错误**（字段映射与后端契约不一致），一并修复。

## 二、根因分析

### 根因 1：列表按 archiveType 过滤不匹配 → 真实记录全被过滤

提交记录列表数据源为 `GET /activities`（6.1 动态记录），其返回的 `archiveType` 是**后端编码**（如学科竞赛为 `academic_competition`），而前端列表只按 `type` key（如 `competition`）过滤，二者不一致 → **所有真实已提交记录都被过滤掉**，列表为空，表现为"提交成功后不显示记录"。

### 根因 2：草稿仅本地持久化，但未合并进列表 → 刷新后草稿消失

后端**无草稿更新/删除/详情/提交端点**（`GET/PUT/DELETE /activities/{id}`、`POST /applications/{id}/submit`、`PUT /applications/{id}` 实测均返回 30001 接口不存在），草稿只能落在 `localStorage`；而列表组件只读 `GET /activities`，不读取本地草稿 → 保存草稿后列表不显示，刷新后草稿数据虽在 localStorage 但列表仍不展示。

### 根因 3：提交契约字段映射错误 → 10003 / 60005

经 ~40 次 curl 探测实测后端行为：

- **枚举字段**（`projectType`/`orgLevel` 等）后端**只接受枚举码**（如 `practice`/`school`），提交中文 label（如"创业实践"/"校级"）返回 10003；且**必填**（缺失返回 60005 数据校验失败）。
- **部分自由文本字段**（实习 `location`/`position`、实践 `practiceLocation`/`practiceUnit`、实训 `projectContent`、组织 `positionTitle`）后端**仅接受 ASCII/数字**，含中文返回 10003（空值可存）。
- **学术研究**契约要求 `startDate`+`endDate` 均必填且 end>start，表单此前仅一个单月份字段（`projectDate`），缺失 `endDate` → 60005。
- **未知字段后端忽略**：多余字段不报错，但缺必填项会失败。

---

## 三、解决思路

1. **草稿本地持久化 + 列表合并展示**：草稿统一写 `localStorage`（key `form_draft_<type>`），列表把本地草稿构造成一条 `status='draft'` 记录置顶合并；提交永远 `POST` 新建（后端无更新端点），提交成功后 `clearDraft` + `loadRecords` 刷新真实列表。→ 草稿与已提交记录同时展示、刷新后草稿仍可见、真实记录以真实 id/状态展示。
2. **列表过滤按别名兼容后端 archiveType**：`ARCHIVE_TYPE_ALIASES` 建立前端 type key ↔ 后端 archiveType 映射。
3. **提交 payload 归一化**：`buildContractPayload` 增加 `enumMap`（中文 label → 枚举码）与 `asciiFields`（非 ASCII 置空串）归一化；补齐 research `endDate`。

## 六、遗留问题 / 待后端

1. **档案详情/编辑/删除缺失**：6.2/6.3/6.4 全部 30001，前端编辑真实记录只能"详情拉取失败→摘要回填→POST 新建"，会重复建记录。
2. **图书心得（book-report）提交被后端拒绝**（全载荷变体 10003/超时）。
3. **中文自由文本字段静默置空**：实习地点/职务、实践地点/单位、实训内容等中文输入提交时会被 `asciiOrEmpty` 置空串，需后端放开 UTF-8 或前端改枚举/提示。
4. **组织"职务"必填但拒绝中文**：用户只能填 ASCII 枚举。
5. **探测草稿清理**：见上文第五节，需后端实现 DELETE 或管理员清理。

## 七、用户验证步骤

1. 进入任一申报页（如学科竞赛）填写内容 → 点"保存草稿" → 下方记录列表出现"xx草稿"。
2. 刷新页面 → 草稿仍在列表顶部，表单自动回填草稿内容。
3. 保存多个草稿（各页分别保存）→ 各页列表均展示对应草稿。
4. 提交 → 列表展示真实已提交记录（真实 id/状态），草稿被清空。
5. 学科竞赛/奖学金/荣誉证书提交通过；创新创业/学术研究/实习/组织/实训/社会实践提交通过（枚举/ASCII 归一化后）。
